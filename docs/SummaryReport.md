## Project Overview
This repository contains my preliminary software development work for **Pet Boarding and Grooming (Pet BAG)**, completed as part of my role on the Global Rain development team. The goal of this project is to modernize Pet BAG’s operations by replacing paper‑based processes with custom software.  

This submission includes:  
- A fully implemented **Pet.java** class based on the UML specification  
- High‑level **pseudocode** for the pet check‑in or check‑out process  
- A **flowchart** illustrating the method logic  
- A written explanation of how object‑oriented programming (OOP) principles were applied  


---

## 🧩 OOP Principles Applied
This project demonstrates key object‑oriented programming principles.  
The `Pet` class encapsulates all pet‑related data using private attributes and public getters/setters, ensuring controlled access. The constructor enforces proper initialization of object state. Although this project focuses on a single class, the UML diagram shows how inheritance and class relationships will be used in the full application. By following the UML structure, the design supports scalability, modularity, and maintainability as additional classes are added to the system.

## Pet.java Class (Summary)
The `Pet` class was created using the UML class diagram provided in the Pet BAG Specification Document.  
It includes:

- All required **attributes** with appropriate data types  
- A fully implemented **constructor** that initializes all attributes  
- **Accessors and mutators** (getters and setters) for each attribute  
- Clear, professional **inline comments** explaining purpose and logic  

This class serves as the foundation for future development of the Pet BAG application.
